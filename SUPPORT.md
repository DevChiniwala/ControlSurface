# Support

ControlSurface is an early open-source release candidate. The fastest path to useful help is to choose the channel that matches the problem.

## Questions and setup help

Use [GitHub Discussions](https://github.com/DevChiniwala/ControlSurface/discussions/categories/q-a) for installation, configuration, instrumentation, and workflow questions. Include the ControlSurface version, deployment method, operating system, and sanitized diagnostics.

## Reproducible defects

Open a [bug report](https://github.com/DevChiniwala/ControlSurface/issues/new?template=bug.yml) when current behavior differs from documented behavior and can be reproduced. Search existing issues first.

## Security vulnerabilities

Follow [SECURITY.md](SECURITY.md) and use a [private security advisory](https://github.com/DevChiniwala/ControlSurface/security/advisories/new). Never publish a credential, exploit, sensitive trace, prompt, model output, customer record, or other private telemetry in an issue or discussion.

## Operational emergencies

The public repository does not provide a commercial support SLA or an emergency response channel. Operators remain responsible for backups, retention, access controls, TLS termination, and recovery procedures described in [docs/OPERATIONS.md](docs/OPERATIONS.md).
